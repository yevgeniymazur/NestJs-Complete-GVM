Web Resources

A short list of web development resources I use for standards, CSS, JavaScript, deployment, layout, and backend tooling.

1) W3C Markup Validation Service

Rating: 9/10

Link: https://validator.w3.org/

The W3C validator checks HTML against official web standards. It helps catch invalid tags, syntax mistakes, and structural issues that can cause layout bugs or inconsistent browser behavior. Using it keeps pages clean, reliable, and easier to maintain.

2) MDN Web Docs – CSS

Rating: 10/10

Link: https://developer.mozilla.org/en-US/docs/Web/CSS

MDN’s CSS documentation explains CSS properties, layout systems, and rules like specificity and inheritance. It’s useful when I need to understand why a style is applying (or not), how to structure responsive layouts, and how to avoid CSS conflicts.

3) MDN Web Docs – JavaScript

Rating: 10/10

Link: https://developer.mozilla.org/en-US/docs/Web/JavaScript

MDN’s JavaScript documentation covers the language, built-in objects, and browser APIs. It’s useful for writing cleaner code, understanding core concepts, and debugging issues without guessing. It also helps verify correct syntax and behavior when building interactive pages.

4) GitHub Pages Documentation

Rating: 9/10

Link: https://docs.github.com/en/pages

GitHub Pages documentation explains how to host a static website from a GitHub repository. It’s useful for learning a real deployment workflow, understanding how updates publish, and troubleshooting common issues when a site doesn’t render correctly after pushing changes.

5) Bootstrap Layout & Grid System

Rating: 8/10

Link: https://getbootstrap.com/docs/4.0/layout/overview/

Bootstrap’s layout documentation explains containers, rows, and columns for responsive design. It’s useful for building clean page structure quickly and keeping layouts consistent across screen sizes without writing a large amount of custom CSS.

6) Node.js Documentation

Rating: 8/10

Link: https://nodejs.org/en/docs

Node.js documentation explains how JavaScript runs on the server and how modern web tooling works. It’s useful for understanding full-stack development, APIs, and project workflows that use packages, scripts, and build tools to support larger web applications.
