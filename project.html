Wanderloom

DEV320 Group Project

Project Focus

A platform for organizing travel photos by trip and eventually exploring them on an interactive globe.

Technology

React, Firebase, JavaScript, HTML, CSS

Back to Profile Web Resources

The Problem

Travel photos are usually stored in folders or camera rolls which makes them difficult to organize and explore geographically. Most systems allow photo storage but do not provide meaningful ways to connect memories to locations.

The Solution

Wanderloom is a travel memory platform that allows users to organize photos by trip folders and eventually explore them through an interactive globe interface. The goal is to make travel memories easier to revisit and visualize across locations around the world.
